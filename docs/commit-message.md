## ✍️ Git Commit Message Prompt

- Write commit messages in the **present tense**.
- Always include a **concise title** followed by a **detailed list** of changes.
- The **title** must start with an **emoji** and summarize the commit in **under 72 characters**.
- The **body** should:
  - List each change on a new line.
  - Start each line with a **different emoji**.
  - Explain what was changed, why, and the impact.
- Use **human-readable phrasing** and avoid technical jargon where unnecessary.

### ✅ Format Template

**Title:**

```
🎯 Short and clear summary of the change
```

**Body:**

```
- 🧩 Explained individual change or addition
- 🔧 Fixed a specific issue or bug
- 📦 Updated dependencies or build scripts
- 📚 Documented the new or changed functionality
```
